## Overview

A Python exchange rate calculator that converts amounts between Canadian dollars (CAD) and US dollars (USD). The program reads annual exchange rates published by the Bank of Canada from a CSV file and uses the most recent USD/CAD rate for the conversion.

- **Data source:** Bank of Canada annual exchange rates, 2017 to 2025
- **Rate used:** `FXAUSDCAD` column, latest row (2025): **1 USD = 1.3978 CAD**

## Part 1: Exchange Rates

### Design

- **`ExchangeRates` class:** takes the CSV file name when created.
- **`__init__`:** reads the file with `csv.DictReader` and stores the latest USD/CAD rate as a private attribute (`self.__rate`).
- **`get_rate`:** returns the stored rate.
- **`convert`:** takes the amount and two currencies and returns the converted amount. Since the rate is quoted as CAD per 1 USD, USD to CAD multiplies by the rate and CAD to USD divides by it.
- **Main block:** prompts the user with `input()`, calls `convert`, and prints the result rounded to the nearest penny with a dollar sign and currency code.

### Code Comparison

For Part 2, I used Opus 5.5 Medium and provided two prompts, listed above, without sharing my Part 1 code. The AI’s first version used standalone functions instead of a class, so I re-prompted it with the Part 1 requirements to restructure the code around an ‘ExchangeRates’ class with a ‘convert’ method. Both final programs produce identical results ($100,000.00 USD = $139,780.00 CAD and $100,000.00 CAD = $71,541.01 USD), but they differ in design, robustness, and readability. My version stores the rate as a private attribute, following the encapsulation principle from Lecture 4, while the AI stores it as a public attribute that code outside the class could change. The two versions also find the latest rate differently: my loop overwrites the stored rate on each row and assumes the last row is the most recent, whereas the AI selects the row with the latest date, skips rows with missing values, and handles the file’s hidden byte-order mark. The AI also added input validation the assignment did not require, such as re-prompting on invalid entries and accepting lowercase currency codes and built the file path so the program runs from any folder. However, its version is roughly twice as long and relies on features not yet covered in the course, which made it harder to read and verify at my current level of understanding. Overall, the AI produced more defensive code quickly, but writing my own version first gave me the understanding needed to evaluate whether its output was correct.
